# Douane-Temporelle

Mini Projet DS1 – Programmation Mobile

## Membres du groupe
- Eya-T-Allah Ghrairi        A06
- Malak Rezgui               A02

## Description du projet
Application Android développée en Java et XML qui simule un poste de douane pour les voyageurs du temps.

## Fonctionnalités
- Enregistrement des informations du voyageur.
- Vérification du risque de paradoxe temporel.
- Approbation ou refus du voyage.
- Affichage du verdict final.
- Possibilité d'enregistrer un nouveau voyageur.
